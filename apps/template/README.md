# MapComponents + vite + react + typescript

This template is based on the vite ts-react template, and adds all
required basic components for a MapComponents application.

## Install packages

```bash
npm i
```

## Start the development server

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

The build checks the application types and writes the production files to `dist/`
inside the app. Run `npm run preview` to serve that build locally.

## Create a new app from this template

```bash
npm create mapcomponents-app@latest my-new-app
cd my-new-app
npm install
```
